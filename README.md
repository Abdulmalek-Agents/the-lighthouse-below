# 🌊 The Lighthouse Below

> *"The deeper you understand, the further you fall."*

A **1–4 player cooperative atmospheric horror game** where a salvage crew dives on the impossible ruins of a pre-human civilization six kilometers beneath the Mariana abyssal plain. Investigation, not combat, is the core loop.

**Pitch in one line:** *Subnautica's awe × Iron Lung's dread × Return of the Obra Dinn's eureka.*

## ▶️ Run the Prototype

1. Download or [view raw](./prototype.html) `prototype.html`
2. Open it in any modern browser (Chrome, Firefox, Safari, Edge)
3. Click **BEGIN DESCENT**
4. Use `W A S D` to pilot. Once deep enough, hold `SPACE` to deploy the diver.
5. **Mouse** aims your flashlight. **Left-click** photographs glyphs.
6. Press `E` near the Anglerfish-IV to ascend.

## 🎯 The Market Gap

## 💰 Revenue Model

- **Base game $29.99** (Steam Early Access → 1.0 → Game Pass Day-1)
- **Free seasonal biomes** + **paid expansion** Year 2
- **Cosmetics only** — no P2W, no loot boxes
- **3-year projection: ~$57.6M gross / ~$35M net** (conservative)

## 🧭 Core Pillars

1. **Atmosphere > spectacle**
2. **Investigation as power fantasy** — understanding *is* the reward
3. **Diegetic everything** — no floating HUDs
4. **The world remembers** — leave tape recordings for future players' runs
5. **Optional hidden-traitor role** — Among Us layer without breaking immersion
